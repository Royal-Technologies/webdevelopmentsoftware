# Web Development Software & Tools

A curated collection of useful software, applications, and developer tools for web designers, web developers, WordPress developers, and IT professionals.

The project provides a simple, searchable web directory of software commonly used for coding, local development, WordPress development, server management, database administration, design, Git, and other development tasks.

## Live Website

https://royal-technologies.github.io/webdevelopmentsoftware/

## Features

* Curated list of web development software
* Search software by name, purpose, or category
* Filter software by category
* Responsive and mobile-friendly design
* Direct links to official websites
* Clean and lightweight interface
* No backend or database required
* Fast client-side search and filtering
* Easy to maintain and extend
* SEO-friendly page structure

## Adding New Software

To add a new tool, add a new table row to `index.html`.

Example:

```html
<tr data-category="Code Editor">
    <td>26</td>
    <td class="software-name">Example Editor</td>
    <td><span class="category">Code Editor</span></td>
    <td class="purpose">Source code editor</td>
    <td>
        <a
            class="visit"
            href="https://example.com"
            target="_blank"
            rel="noopener"
        >
            Visit
        </a>
    </td>
</tr>
```

Update the category filter if a new category is introduced.
